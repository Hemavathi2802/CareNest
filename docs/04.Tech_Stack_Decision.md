# Tech Stack Decision

## Frontend
- JavaScript (ES modules) and React 19
- React Router 7 for client-side routing
- Vite 8 for development and production builds
- Node.js 20.19 or later for frontend tooling and the production static-file server
- CSS for application styling

## Backend
- Java 21
- Spring Boot 3.4.2
- Spring Web for REST APIs
- Spring Data JPA and Hibernate for persistence
- Spring Security for the security filter chain
- Spring Boot Mail for email notifications
- Maven for dependency management and builds

## Database
- MySQL, accessed through MySQL Connector/J
- Connection details are supplied through environment variables
- The MySQL server version is determined by the selected hosting database service

## Testing and Quality
- JUnit and Mockito through Spring Boot Starter Test
- Oxlint for frontend linting
- Postman may be used for manual API testing

## Deployment
- Railway for hosting the frontend, backend, and MySQL service
- Railway/Nixpacks build and start configuration is kept with each application service
- Frontend API origin, backend CORS origin, database credentials, and mail credentials are configured as environment variables

## Version Control and Repository
- Git
- GitHub

## Architecture
- React single-page application served as static files
- Spring Boot backend exposing REST endpoints
- MySQL relational database
